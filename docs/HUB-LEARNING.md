# Hub de Conhecimento — modelo de aprendizagem

## Estrutura

`trilha → módulo → aula → atividade → conclusão → certificado`

Cada aula combina, quando aplicável:

1. objetivo claro;
2. leitura bíblica;
3. texto explicativo curto;
4. vídeo ou áudio opcional;
5. checagem de compreensão;
6. prática ou missão;
7. conclusão explícita pelo aluno.

Vídeo nunca é a única forma de acesso. Toda mídia precisa de resumo, transcrição ou alternativa textual. YouTube deve usar identificador validado, domínio de incorporação aprovado e modo de privacidade aprimorada; HTML arbitrário não será armazenado.

## Conclusão do módulo

O módulo é concluído quando:

- todas as aulas obrigatórias foram concluídas;
- todas as leituras obrigatórias foram marcadas;
- o quiz final atingiu o critério definido, inicialmente 70%;
- a missão obrigatória foi concluída;
- uma eventual validação humana foi realizada.

O aluno pode revisar e refazer atividades. A conclusão demonstra atendimento aos requisitos educacionais, não condição espiritual.

## Gamificação

- progresso privado;
- XP em livro-razão imutável;
- medalhas por marcos educacionais;
- sequência com recuperação, sem punição ou vergonha;
- missões colaborativas;
- ausência de ranking público.

Proposta inicial de XP: leitura `10`, aula `10`, quiz `20`, missão `30` e conclusão do módulo com medalha. Os valores serão configuráveis e não interferem no Radar Pastoral.

## Certificado por módulo

Campos: aluno, trilha, módulo, carga horária, data, versão concluída, código aleatório, QR Code, estado e signatários. Estados: `valid`, `revoked`, `replaced`.

A validação pública revela apenas nome minimizado para menores, módulo, instituição, data e validade. O documento declara: **“Este certificado reconhece a conclusão de uma atividade educacional de discipulado. Não representa avaliação de fé, espiritualidade, ordenação ou habilitação ministerial.”**
